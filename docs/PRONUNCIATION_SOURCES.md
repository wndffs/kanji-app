# Recorded Pronunciation Policy

This is separate from browser speech synthesis. Do not infer human origin from
a voice/speaker name. Unknown origin remains unknown; no TTS substitution for
a listening exercise. Existing legacy listening assets are not retrospectively
certified by this policy.

The initial one-word wave binds 食べる / たべる to the existing exact JMdict
identity and one original, unmodified WAV file from Lingua Libre, spoken and
recorded by Fukujinzuke on 2026-10-05. The [file-specific source revision](https://commons.wikimedia.org/w/index.php?oldid=1283603638&title=File%3ALL-Q5287_%28jpn%29-Fukujinzuke-%E9%A3%9F%E3%81%B9%E3%82%8B.wav)
declares [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Attribution
must include author, source, license and unchanged status. The structured-data
public-domain field is not treated as a substitute for the actual file license.
No WaniKani/Tofugu-origin recordings are eligible, even when separately licensed.

The versioned source registry pins source revision/date, exact target identity,
SHA-256, byte size, PCM duration and publication path. Source and media evidence
do not claim native-speaker/acoustic certification. Listening at word scale is
not JLPT listening comprehension. The production media is intentionally checked
in; temporary downloads and analysis stay outside the repository. No runtime
download, scraping, license guessing or remote audio hotlink is required.

An explicit operator plan/apply records License, DataSource, successful ImportRun
and AudioAsset provenance in Neon. It never creates/replaces LearningCard,
LearningAnswer, SRS state, enrollment or finite-course source records. Assets
are served only when the published database record matches the pinned manifest.
The finite course counts and all V1-V6 seals stay unchanged.
