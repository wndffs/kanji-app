# UI Dependencies

`lucide-react` 1.61.0 (npm range `^1.61.0`), ISC license, is used for a consistent
set of compact navigation/control icons. This avoids bespoke SVG paths for
standard actions. Named imports allow bundlers to retain only used icons.
Buttons keep accessible names and visible hover tooltips. Registry version and
license metadata were checked with `npm view lucide-react version license` on
2026-10-23. No educational data or competitor artwork is included.
